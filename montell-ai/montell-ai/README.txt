Обновление сайта Montell AI

Загрузите index.html, chat.js, chat-config.js, scroll-reveal.js и demo_ukr.mp4 и demo_eng.mp4 в одну папку сайта на GitHub с заменой файлов.

Чат сейчас работает локально по демонстрационным сценариям. Он не создаёт реальные записи и не отправляет сообщения на сервер.

Подключение n8n позже:
1. В chat-config.js укажите HTTPS production URL вебхука в webhookUrl.
2. Чат отправляет POST JSON: { action: "sendMessage", sessionId: "...", chatInput: "..." }.
3. Вебхук должен возвращать JSON { "output": "Текст ответа" } (также поддерживаются reply и text).
4. Настройте CORS для домена сайта и обработку OPTIONS. Секретные ключи храните на сервере, не в chat-config.js. Для публичного вебхука настройте ограничение частоты запросов.
5. После подключения обновите подписи демо-режима под фактические возможности агента.

Подписка в футере открывает почтовый клиент с запросом на подписку; автоматическая рассылка не подключена.
В футере добавлен Telegram из макета. Для Instagram, Facebook, LinkedIn и YouTube нужны точные ссылки — фиктивные адреса не добавлялись.


Превью ссылки:
Загрузите все файлы этой папки в корень статического сайта с заменой. preview.png должен лежать рядом с index.html: это обычный HTML-проект без сборщика, поэтому папка public не нужна.
После деплоя проверьте https://montell-site.vercel.app/preview.png — ссылка должна открывать изображение.
Open Graph и Twitter Card находятся непосредственно в HTML. Favicon не изменён: отдельного файла логотипа в проекте нет.
Проверка опубликованного сайта и обновление кэша мессенджеров в этот архив не входят.

Две языковые версии (украинский / English):
Загрузите ВСЕ файлы из архива в корень сайта с заменой существующих файлов.
index.html — украинская версия; en.html — английская версия.
language.js — переключатель с сохранением выбора; chat-en.js — английский демо-чат.
Переведены тексты страницы, формы, FAQ, чат и метатеги английской страницы.
Выбор сохраняется в браузере. Ссылки /?lang=uk и /en.html?lang=en задают язык явно.
Видео меняется вместе с языком: index.html использует demo_ukr.mp4, en.html использует demo_eng.mp4. Картинка preview.png остаётся украинской.
При будущем подключении n8n чат также передаёт language: "uk" или "en".
Проверены переключение в обе стороны, сохранение выбора, английский ответ чата и мобильная ширина 375px.
