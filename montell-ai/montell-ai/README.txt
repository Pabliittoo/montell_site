Montell AI — ShaderGradient + Liquid Glass

Публикация:
1. Загрузите все файлы и папку assets из этого архива в корень текущего сайта на GitHub с заменой.
2. Сохраните папку assets целиком: в ней находятся собранные эффекты и лицензии.
3. Дождитесь успешного деплоя Vercel. Настройки сборки менять не нужно — это готовый статический сайт.

Изменения:
- Настоящий ShaderGradient 2.4.20: медленный фиолетово-синий WebGL-фон первого экрана.
- Шейдер Container из dashersw/liquid-glass-js: стеклянная шапка и кнопка просмотра примера на компьютере.
- Адаптер стекла получает живую текстуру из фона; html2canvas и снимки всей страницы не используются.
- Переключатель языка оформлен полупрозрачным стеклом CSS.
- На экранах до 760px стекло работает через CSS, фон рендерится с пониженным разрешением.
- Если включено уменьшение движения, нет WebGL2 или устройство сообщает не более 2GB памяти / 2 потоков CPU, используется статический CSS-фон.
- Анимация приостанавливается вне первого экрана и в скрытой вкладке.
- УКР/EN, соответствующие видео, демо-чат и Open Graph сохранены.

Библиотеки уже включены в assets/effects.js. Для работы эффектов CDN не нужен.
Публикация в GitHub/Vercel автоматически из этой задачи не выполнялась.

Светлая и тёмная темы:
- Кнопка солнца/луны в шапке переключает оформление всего сайта и демо-чата.
- Выбор сохраняется в браузере и переносится при переключении УКР/EN.
- По умолчанию используется тёмная тема.
- Заголовки исправлены: увеличена высота строки и область отрисовки градиента, чтобы нижние части букв не обрезались.
- На узких телефонах кнопка демонстрации скрыта только в шапке для размещения переключателей; основная кнопка на первом экране сохранена.
- Для публикации загрузите содержимое архива вместе с assets, заменив файлы.
